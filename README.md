# power-bi-sales-dashboard
Built an interactive Power BI sales dashboard (Power Query, DAX, star-schema model) analysing revenue, profit and budget variance across regions and products.
Sales Performance Dashboard | Power BI, Power Query, DAX

Built an end-to-end sales dashboard that tracks revenue, profit, margin and
orders across regions, products and categories, and compares actual sales
against budget.

- Combined three monthly sales files into one dataset and cleaned it in
  Power Query (trimmed text, converted dates, removed blanks and duplicates)
- Designed a star-schema data model linking Sales, Date, Products, Customers,
  Regions and Budget tables
- Wrote DAX measures for Total Sales, Total Profit, Profit Margin %, Total
  Orders, Average Order Value and Sales vs Budget %
- Created an interactive one-page dashboard with KPI cards, a monthly trend,
  a regional comparison, top 5 products and category breakdown, filtered by
  month, region and category
